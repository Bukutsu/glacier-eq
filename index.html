Glacier EQ

Glacier EQ is free EQ software for USB DAC dongles including the EPZ TP35 Pro, TRN Black Pearl, Moondrop Dawn Pro, FiiO JA11, FiiO KA series, Truthear KEYX, JCally JM20, JCally JM12, Fosi Audio DS2, iBasso DC04 Pro, and Audiocular Aura. Edit parametric EQ bands, push DSP filters to hardware, match AutoEQ targets, compare measurements, and save profiles — all offline, no account needed.

Supported devices: EPZ TP35 Pro (TP35Pro), TRN Black Pearl, Audiocular Aura, Fosi Audio DS2, iBasso DC04 Pro, JCally JM20, JCally JM20 Pro, JCally JM12, Moondrop Dawn Pro, Moondrop Dawn Pro 2, FiiO JA11, FiiO KA series, and Truthear KEYX. Source code and release downloads are available on GitHub.
